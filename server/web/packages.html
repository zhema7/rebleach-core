出包中心

服务端启动目录下的 packages/ 目录即出包中心仓库，把构建产物放进去即可在此分发。 点击文件名直接下载。

构建命令参考 
# 被控端 / 主控端 CLI
cargo build --release -p rebleach-client
copy target\release\rebleach-client.exe packages\

# 主控端安装包（MSI / NSIS，需安装 cargo-tauri）
cd app
cargo tauri build
copy src-tauri\target\release\bundle\msi\*.msi ..\packages\
copy src-tauri\target\release\bundle\nsis\*.exe ..\packages\
文件名大小更新时间

每 10 秒自动刷新。
